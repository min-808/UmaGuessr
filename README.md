# UmaGuessr

UmaGuessr is a Discord bot based on the Cygames release, Uma Musume

The main function of the bot is the *guessing game*. You'll be presented with a random, pixelated image of one of the characters in the game, and be tasked with guessing the character in the image within **60** seconds. If you guess correctly, you'll be rewarded with a number of points depending on the difficulty of the region you're playing on. However, if you don't manage to guess the character, someone else can steal the points and break your streak.

Hints are also available to slightly unblur the image, but using more hints will lessen the total number of points you can earn.

You can also fully unblur the image, or skip the current game and start a new one with the buttons on the embed. Note that skipping the current game can **only** be done by the original starter of the game, and it will break your streak.

A newly introduced multi-mode is now available for those looking for a harder challenge. Multiple characters will be shown in the image, and players can guess the characters by sending their names one-by-one into the chat. Currently, this mode does not affect streak or best times.

## Features

- Global and server-wide leaderboards (`!lb` / `/leaderboard`)
- Profile viewing (`!p` / `/profile`)
- Setting a default region for games (`!set` / `/set`)
- Daily rewards (`!daily` / `/daily`)
- Voting (`!vote` / `/vote`) and redeemable voting rewards (`!redeem` / `/redeem`)
- Customizable server prefix (`!prefix` / `/prefix`)
- Uma character profiles (`!char` / `/character`)
- Total list of characters (`!cl` / `/charlist`)
